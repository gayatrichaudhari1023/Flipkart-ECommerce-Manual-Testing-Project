# Flipkart E-Commerce Web Application Testing

## 📌 Project Overview
This project demonstrates the end-to-end Functional Manual Testing of the Flipkart E-Commerce platform. The main goal was to identify critical functional bugs, boundary-value issues, and ensure a seamless user experience.

## 🛠️ Tools & Technologies Used
* **Documentation:** Microsoft Excel / Google Sheets
* **Testing Concepts:** Software Testing Life Cycle (STLC), Agile Methodology, Test Case Designing
* **Defect Tracking:** JIRA (Basics)

## 🗂️ Modules Tested
1. **User Authentication:** Valid/Invalid Login validation using mobile number and OTP.
2. **Product Search & Filters:** Brand search accuracy and special character boundary testing.
3. **Cart Management:** Product addition, cart count updates, and quantity increment validations.
4. **Checkout Flow:** End-to-end user navigation up to the payment gateway screen.

## 📄 Deliverables Attached
Flipkart_ECommerce_Manual_Testing_Project.xlsx:** Contains comprehensive operational test cases with Test ID, Description, Steps, and Expected Results.
